Đặt ảnh PNG cho nhân vật vào các thư mục sau:

0. Base (trạng thái đứng yên mặc định):

   - Hoặc 4 frame: base_0.png .. base_3.png

2. Walk (4 hướng x 4 frame = 16 file):

   - walk_down_0.png .. walk_down_3.png
